# Changelog

## 0.2.0 — 2026-10-09

- Reusable GitHub Action with failure annotations, job summaries, and count outputs.
- Isolated execution of the bundled validator without pip installation or model calls.
- Shared bounded JSON loader for the CLI and action; deeply nested invalid JSON fails cleanly.
- Action integration tests for success and expected failure on Windows/Linux and Python 3.10/3.13.
- Copyable English and Chinese workflow examples and an action reference.

## 0.1.0 — 2026-10-09

- Exact and opt-in whitespace quotation matching.
- Original character spans, inclusive line ranges, and repetition detection.
- Optional source fingerprint checks and multi-source JSON bundles.
- CLI with text, JSON, and self-contained HTML output.
- Offline six-case demo, integration example, and English/Chinese documentation.
- Standard-library regression tests and Windows/Linux CI configuration.
